# 프로미스 성경 예배당 — 공개 사이트 만들기

링크만 있으면 누구나 이름을 적고 들어와 함께 걷고, 앉고, 성경을 읽고, 읽은 장을 기록하는 사이트예요.
두 가지 무료 서비스를 써요.

- **Firebase** (Google): 누가 어디 있는지, 누가 무엇을 읽었는지 실시간으로 저장해요.
- **GitHub Pages**: 이 폴더를 인터넷 주소로 공개해요.

---

## 1단계 · Google 계정과 Firebase (약 10분)

1. Google 계정이 없다면 accounts.google.com 에서 만들어요.
2. console.firebase.google.com 에 들어가 **프로젝트 만들기**를 눌러요.
   - 이름: `promise-chapel` (아무 이름이나 괜찮아요)
   - Google 애널리틱스는 **사용 안 함**으로 두고 만들어요.
3. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**를 눌러요.
   - **로그인 방법** 탭에서 **익명**을 골라 **사용 설정** 후 저장해요.
   - (방문자는 로그인 화면을 보지 않아요. 브라우저마다 보이지 않는 번호가 자동으로 붙어요.)
4. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**를 눌러요.
   - 위치: **싱가포르 (asia-southeast1)**
   - 보안 규칙: **잠금 모드**로 시작
5. 만들어지면 **규칙** 탭을 열어 내용을 모두 지우고, 이 폴더의 `firebase-rules.json` 내용을 붙여넣고 **게시**를 눌러요.
6. 왼쪽 위 **톱니바퀴 → 프로젝트 설정 → 일반** 아래쪽 **내 앱**에서 웹 아이콘(`</>`)을 눌러요.
   - 앱 이름: `chapel`, "Firebase 호스팅"은 체크하지 않아요.
   - 화면에 나오는 `firebaseConfig = { ... }` 안의 내용을 복사해요.
7. 복사한 내용을 Claude와의 대화에 붙여넣으면, 설정이 들어간 파일을 다시 만들어 드려요.
   (직접 하려면 `config.js`를 메모장으로 열어 같은 이름의 칸에 값을 채워요. `databaseURL`도 꼭 들어가야 해요.)

## 2단계 · GitHub 계정과 GitHub Pages (약 5분)

1. github.com 에서 **Sign up**으로 계정을 만들어요. 이 아이디가 사이트 주소에 들어가요.
2. 오른쪽 위 **+ → New repository**를 눌러요.
   - Repository name: `promise-chapel`
   - **Public** 선택 → **Create repository**
3. 만들어진 화면에서 **uploading an existing file** 링크를 눌러요.
4. 압축을 푼 `promise-chapel` 폴더 **안의** 파일과 `b` 폴더를 모두 끌어다 놓아요.
   (`index.html`이 맨 위 칸에 있어야 해요.) 업로드가 끝나면 **Commit changes**를 눌러요.
5. 위쪽 **Settings → 왼쪽 Pages**로 가서
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/(root)** → **Save**
6. 1~2분 뒤 같은 화면 위쪽에 주소가 떠요.
   `https://내아이디.github.io/promise-chapel/`
   이 주소를 단톡방에 공유하면 끝이에요.

---

## 알아두면 좋은 점

- **기록 유지**: 같은 휴대폰·같은 브라우저로 다시 오면 기록이 이어져요. 시크릿 창, 카카오톡 안 브라우저, 방문 기록 삭제 후에는 새로 시작해요. 같은 이름의 기록은 그룹 진도에서 함께 모여요.
- **공개 범위**: 링크를 아는 사람은 누구나 들어올 수 있어요. 이름과 읽은 장은 들어온 사람 모두에게 보여요.
- **무료 한도**: Firebase 무료 요금제는 동시 접속 100명, 월 10GB 다운로드까지예요. 소그룹 모임에는 충분해요. 콘솔의 **Realtime Database → 사용량**에서 확인할 수 있어요.
- **기록 정리**: 장난 기록이 생기면 Firebase 콘솔의 **Realtime Database → 데이터**에서 `readers` 아래 항목을 지울 수 있어요.
- **본문**: 성경전서 개역한글판 (대한성서공회, 1961), 저작권이 만료된 공개 본문이에요.
